A hardware wallet's one-line excuse for refusing to sign a transaction at 3 AM, written by a Node 22 program to /output/entry.txt. The wallet plays a night-shift worker whose keys are off the clock: it already signed the user's 2 AM "emergency", and the next signature happens at sunrise.

## Run it

```sh
node main.ts
```
